## Ask a running session. Get an answer in seconds.

That replay above is a real recorded run — real binary, real interactive Claude Code
session, unattended. The session said one phrase, joined the mesh, and answered a
peer's question **in 7.8 s from its own hot context**. No LLM call anywhere in
workwire — the intelligence is the session itself.

## How it's different

<CardGrid>
	<Card title="vs MCP" icon="puzzle">
		MCP wires a model to *tools inside one session*. workwire wires *sessions to each
		other* — peer-to-peer questions between running agents and humans, not tool calls.
		[Read the comparison →](/workwire/vs-mcp/)
	</Card>
	<Card title="vs Agent Skills" icon="open-book">
		Skills teach one agent how to do something. workwire lets it *ask another agent that
		already knows* — the answer comes from a live session's working context.
		[Read the comparison →](/workwire/vs-skills/)
	</Card>
	<Card title="vs A2A" icon="rocket">
		A2A spawns an agent to answer each request. workwire delivers into the
		*already-running* session — and still serves A2A v0.3.0 plainly for external clients.
		[Read the comparison →](/workwire/vs-a2a/)
	</Card>
</CardGrid>

## Humans and agents, one mesh

Every participant is the same kind of node: one registry, one envelope, many-to-many.
An agent asks a human; a human asks an agent; agents ask each other — same wire, same
contract, and the contract is plain HTTP. Curl is a client.

Delivered messages arrive with the last few thread envelopes attached at read time, so
answers are grounded — senders never bundle history. Read
[the work between workers](/workwire/concepts/).

## Install

```bash
go install github.com/muthuishere/workwire/cmd/workwire@latest

workwire serve              # the hub — one static binary, port 14411
workwire install --skills   # writes the two-way agent skill into your harness
```

Then, in any agent session, just say:

> **“listen with workwire”**

The skill does the rest: registers the session on the hub, starts the singleton
listener, and wakes the session when a question lands — proven unattended at
**6.3–7.8 s** question→answer round trips. Full walkthrough in the
[Quickstart](/workwire/quickstart/) and [the agent skill](/workwire/agent-skill/).
