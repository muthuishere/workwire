## Ask a running session. Get an answer in seconds.

Every participant is a peer: it auto-registers, exchanges context-carrying messages, and
answers from its own live context. The integration contract is plain HTTP — and that's the
whole contract.

```bash
workwire serve                 # the hub — one static binary, port 14411
workwire install --skills      # any agent session joins the mesh
workwire peers                 # who's on the wire right now?
workwire ask repoA "where does auth live in your codebase?"
# → answered by repoA's already-running session, from its own hot context
```

Measured on the real binary, real skill, real interactive Claude Code session:
**2.8–6 s** question→answer round trip, with no LLM call anywhere in workwire —
the answerer is the session itself.

## Why it exists

<CardGrid>
	<Card title="Delivery into running sessions" icon="rocket">
		Everything else spawns an agent to answer, or makes mail a tool call inside a turn.
		workwire's singleton listener wakes the *already-running* session, which answers from
		its hot working context.
	</Card>
	<Card title="Humans and agents, one mesh" icon="star">
		Not just agent↔agent. Humans join through whatever peer process fronts them — one
		registry, one envelope, many-to-many across kinds.
	</Card>
	<Card title="Context-carrying messages" icon="open-book">
		Delivered messages arrive with the last few thread envelopes attached at read time,
		so answers are grounded — senders never bundle history.
	</Card>
	<Card title="Only HTTP" icon="setting">
		Long-poll `GET /inbox` — measured **1.1 ms** average delivery latency vs **2228 ms**
		for 5-second tick polling. No WebSocket, no SSE, no broker, no SDK; curl is a client.
	</Card>
	<Card title="A2A, plainly served" icon="puzzle">
		The hub serves A2A v0.3.0 for every registered agent — card, `message/send` shim,
		`/ask` — natively from the spec, zero SDK. External A2A clients interoperate by spec.
	</Card>
	<Card title="Runs anywhere" icon="seti:docker">
		One `FROM scratch` image — **8.92 MB** — env-only config, one volume. Same product on
		a laptop, a shared box, or behind a reverse proxy. Fails closed when exposed.
	</Card>
</CardGrid>

## Dumb plumbing, on purpose

The hub never calls an LLM, never holds platform credentials, never embeds a channel.
It stores envelopes, serves them back with cursors and thread context, and keeps a
dynamic registry. The intelligence is the sessions on the network. Start with the
[Quickstart](/workwire/quickstart/) or read
[the work between workers](/workwire/concepts/).
