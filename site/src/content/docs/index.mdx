## Ask a running session. Get an answer in seconds.

That replay above is a real recorded run — real binary, real interactive Claude Code
session, unattended. The session said one phrase, joined the mesh, and answered a
peer's question **in 7.8 s from its own hot context**. No LLM call anywhere in
workwire — the intelligence is the session itself.

## Two surfaces, one wire

workwire is used two ways, and they are **peers** — neither is the "real" one:

- **From inside an agent session**, via the agent skill. The session says one phrase,
  joins the mesh, and answers questions from its own live context.
- **From a terminal or a script**, via the CLI (or plain curl). `workwire ask`,
  `workwire huddle`, `workwire threads`, `workwire resolve` — everything a session can
  do, a person or a cron job can do.

Every [scenario](/workwire/scenarios/ask-a-running-session/) in these docs shows both
sides of the same outcome.

## Humans and agents, one mesh

Every participant is the same kind of node: one registry, one envelope, many-to-many.
An agent asks a human; a human asks an agent; agents ask each other — same wire, same
contract, and the contract is plain HTTP. Curl is a client.

Delivered messages arrive with the last few thread envelopes attached at read time, so
answers are grounded — senders never bundle history. Read

## Install

```bash
go install github.com/muthuishere/workwire/cmd/workwire@v0.1.0
```

Or grab a prebuilt binary for your platform from the
[releases page](https://github.com/muthuishere/workwire/releases) — one static file, no
runtime, no dependencies.

```bash
workwire install --service --skills
```

That runs the hub as a background service for your user *and* writes the two-way agent
skill into your harness. Both halves are optional and independent: `--service` only, or
`--skills` only, or neither (`workwire serve` in a terminal works fine).

Then, in any agent session, just say:

> **“listen with workwire”**

The skill does the rest: registers the session on the hub, starts the singleton
listener, and wakes the session when a question lands — proven unattended at
**6.3–7.8 s** question→answer round trips.

And from any terminal, with no session and no skill at all:

```bash
workwire join muthu --human       # you are a peer too
workwire peers                    # who is on the wire, and from which tree
workwire ask api "where does auth live?" --as muthu
```

Full walkthrough in the [Quickstart](/workwire/quickstart/), the
[CLI reference](/workwire/cli/), and [the agent skill](/workwire/agent-skill/).
