this site are the narrative; these are the sources of truth in the repository.

## Architecture Decision Records

[`docs/adr/`](https://github.com/muthuishere/workwire/tree/main/docs/adr)

- **ADR-001** — hub-core is a dumb, LLM-free, HTTP-only message hub (envelope, cursors, long-poll, config)
- **ADR-002** — hub-native A2A registry and relay, no client-library dependency (pinned v0.3.0)
- **ADR-003** — the two-way agent skill: auto-register + subscriber answer loop
- **ADR-004** — workwire ships only HTTP; every non-agent participant is an external peer (zero channel code)
- **ADR-005** — contacts directory: find people without raw ids (TOFU)
- **ADR-006** — the hub is container-portable: local and hosted are the same product
- **ADR-007** — identity and auth: hub-issued credentials, explicit `authMode`, fail-closed exposure
- **ADR-008** — retention, tombstone deletion, and liveness lifecycle

## The standards workwire speaks

- **[Agent2Agent (A2A)](https://a2a-protocol.org)** — served natively at v0.3.0: card,
  `message/send` shim, plain ask. See [vs A2A](/workwire/vs-a2a/).
- **[Agent Skills](https://www.anthropic.com/news/skills)** — the packaging workwire ships
  in: `workwire install --skills`. See [vs Agent Skills](/workwire/vs-skills/).
